# Chapter 1 — The Diary

English voiceover, burned-in Arabic subtitles. Demo clinic, Arabic UI, 1920x1080.
Beats match `CHAPTERS.diary` in `scripts/promo-chapters.mjs` one-to-one, by number.

Recorded on the **desk dashboard** (`/`), not the appointments page. Same day and week views in a
denser layout, and an empty slot there is itself the booking button: clicking a gap opens the
modal with that time already filled in, which is both fewer steps and a better thing to watch.

The booking made here is really written to the demo clinic, which is why the day visibly changes
at the end. Run `promo-clean-bookings.mjs` between takes or they stack up.
