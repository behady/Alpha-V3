# Alpha Dental — 90-second feature reel

English voiceover (AI, male) over silent screen capture, with **burned-in Arabic subtitles**.
Landscape 1920x1080. Demo clinic only: `Tbog4tv8bA4E0BqO6NWF`. Re-seed before recording.

The **Narration** column is what gets spoken and is the input to `make-promo-voice.mjs`.
The **Subtitle** column is what gets burned on screen and is the input to `make-promo-subs.py`.
They are separate columns on purpose: a subtitle that is a word-for-word transcript of English
read aloud is too long to read in the time the line takes. The Arabic here says the same thing,
shorter.

The app itself is recorded in **Arabic**, which is deliberate — the audience is Egyptian and the
subtitles are Arabic, so the UI matching them reads as one piece.
